# CampusLink

CampusLink is a full-stack social networking platform designed for university students.

## Features

- User Authentication (JWT)
- User Profile
- Avatar Upload
- Create Post
- Image Upload
- Like / Unlike
- Comment System
- Responsive Dashboard

## Tech Stack

### Frontend
- React
- Axios
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
- JWT
- Multer

## Installation

### Backend

```bash
cd backend/server
npm install
